# Project Context

This document captures the high-level expectations for the deliverable. Detailed requirements are in `assignment.md`. Quality guidance is in `take-home-challenge-guide.md`.

## Expected Deliverable

The submission should include:

- as many relevant, well-executed features as possible
- a polished design and a strong UX/UI
- a working application that can be run locally with clear instructions
- clean, understandable implementation
- documentation that covers setup, usage, and the main architectural decisions

More scope is better when each addition is stable, useful, and consistent with the rest of the product. Unfinished features are not.

## Priorities

- Reviewer clarity
- Product judgment
- Working software
- Polished end-to-end experience
